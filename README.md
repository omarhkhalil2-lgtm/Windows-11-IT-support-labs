# Windows 11 IT Support Labs

**Omar Khalil | Portland Community College | Cybersecurity AAS Student**

## Project Overview

This repository showcases four hands-on Windows 11 labs completed as part of my CIS 140M coursework at Portland Community College.

Using Hyper-V, XtremeLabs, and Windows administration tools, I practiced operating system configuration, virtualization, command-line operations, hardware and disk management, troubleshooting, and system maintenance.

These guided academic labs demonstrate foundational technical skills relevant to entry-level Help Desk, Desktop Support, and IT Support Specialist positions.

## Technical Skills and Tools

- Windows 11 configuration and administration
- Hyper-V Manager and virtual machines
- Windows Command Prompt (CMD)
- Windows Settings and File Explorer
- Disk Management and Device Manager
- Task Manager and Resource Monitor
- Disk Cleanup and storage management
- Technical documentation and troubleshooting

## Featured Labs

### Lab 1 — Windows 11 Virtualization and Command-Line Fundamentals
Explored Windows 11 installation and system information in a Hyper-V virtual machine, managed checkpoints, and practiced Command Prompt navigation, file listings, and directory operations.

### Lab 2 — Windows 11 Configuration and User Support
Practiced Windows personalization, accessibility settings, printer and scanner setup options, and file organization through guided end-user support scenarios.

### Lab 3 — Windows Hardware and Disk Management
Used Windows Disk Management, Device Manager, drive optimization, and disk-checking tools to inspect and document hardware and storage configurations.

### Lab 4 — Windows System Performance and Maintenance
Explored Windows Update Delivery Optimization, Task Manager, storage usage, Disk Cleanup, power settings, and Resource Monitor to understand system performance and maintenance.
